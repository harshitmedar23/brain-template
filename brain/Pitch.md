# Pitch.md — 3-minute script

| Time | Beat | Say |
|---|---|---|
| 0:00 | Hook | One shocking stat or real scenario about the problem |
| 0:20 | Problem | Who suffers, why current solutions fail |
| 0:40 | Solution | One sentence + name |
| 0:55 | LIVE DEMO (60–75s) | Data flowing → prediction → alert → explanation → what-if |
| 2:10 | How it works | Architecture slide, 3 key tech choices |
| 2:30 | Impact | Numbers: accuracy, time/cost saved, who benefits |
| 2:45 | Future | Scale, integrations, business model |
| 2:55 | Close | Memorable line + thank you |

## Judge-proofing
- Say honestly what's real vs simulated
- Show metrics vs baseline ("X% better than naive")
- Know: data source, model choice, why real-time, how it scales, limitations
- One person speaks, one drives the demo
- Rehearse with a timer ×3

## Likely Q&A
1. How accurate? On what split? 2. What if data is noisy/missing? 3. How does it scale? 4. How is it different from existing tools? 5. Privacy/security? 6. Business model/adoption path? 7. What would you build next?
