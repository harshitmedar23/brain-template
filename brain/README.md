# 🧠 BRAIN — Manthan Hackathon (29 Oct)

This folder is the single source of truth for the project. Every AI chat/tool reads THIS first.

## Read order for any AI session
1. Memory.md (current state). If it says UNCONFIGURED → follow BOOTSTRAP.md
2. Rules.md
3. PRD.md
4. Architecture.md
5. Phases.md (find the current phase)
6. Design.md (only for UI work)

## Files
| File | Purpose |
|---|---|
| BOOTSTRAP.md | START HERE: how the AI configures this brain from a problem statement |
| Memory.md | Living state (UNCONFIGURED until bootstrap runs) |
| plan.md | Master plan: prep timeline, event-day schedule, roles, risks |
| instruction.md | How to talk to the AI + session start/end prompts |
| setup.md | Machine, accounts, installs, repo bootstrap |
| Toolkit.md | Skills, plugins, extensions, MCP servers, libraries |
| PS_Decoder.md | 15-min worksheet to turn the on-the-spot PS into PRD |

| Architecture.md | Flow, folders, stack |
| Rules.md | Guardrails for the AI |

| Design.md | Colors, fonts, UI rules |
| Prompts.md | Copy-paste prompts |
| Pitch.md | Judging pitch script |
| Demo_Checklist.md | Final 2 hours checklist |

## Golden rule
Docs first, code second. If the AI drifts, point it back to the docs — don't re-explain.
